# PeakHuman — Production Description

PeakHuman — минималистичная, но полноценная **production OS** для пиковой производительности. Не демо, а рабочий продукт на **Next.js 16 + Tailwind 4 + Supabase (RLS) + Vercel + Three.js + Framer Motion**.

## Логика продукта — как в жизни

### Утро (05:00–15:00) — план
Пользователь открывает дашборд утром и видит **утренний ритуал**:
- **Намерение дня** — текстовое поле «Сегодня действую как…»
- **Топ-3 приоритета** — 3 инпута (обязательно 1, остальные опционально)
- **Энергия утром** 1–10
- Кнопка **«Пройти утренний ритуал»** → сохраняет в `daily_rituals.morning_*` и ставит `morning_done=true`

Без утра вечер не откроется честно — система подсказывает «сначала утро».

### Вечер (15:00–23:59) — рефлексия
Вечером открывается **вечерний ритуал**:
- **Что получилось** — что из топ-3 и привычек сделано
- **Благодарность** — за что благодарен
- **Урок дня** — чему научился
- **Оценка дня** 1–10
- Кнопка **«Сохранить вечер»** → `evening_*` + `evening_done=true`

Утро + вечер = закрытый цикл дня. Если оба сделаны, день считается завершённым, влияет на streak и динамику.

### Динамика — отслеживание
- **Peak Score** считается из `daily_metrics` (энергия 30% + фокус 30% + сон 20% + привычки 20%) — показывается в дашборде, в heatmap 30 дней, в графике 7/30
- **Heatmap 30 дней** — цвет по Peak (от `#F5F5F3` до `#0A0A0A`)
- **График 7/30** — Peak + энергия×10 + фокус×10, переключатель диапазона
- **История** — лента до 30 дней с бейджами пик/норм/спад, сводка (средний Peak, дней отмечено, streak, привычек)
- **Корреляция** — инсайт: «сон 6.5ч → энергия проседает», «фокус 8.1 при сне 7.2 — поток», тренд +8/-8 за неделю

### Роадмап — свой путь
Страница `/roadmap`:
- Создание роадмапа: **title + quarter** (Q1–Q4, 2026, 90 дней)
- Внутри — **вехи (milestones)**: добавить, отметить done, прогресс-бар `done/total`, анимация
- Удаление роадмапа каскадом
- Прогресс считается локально и в Supabase, динамика подсказывает «в процессе / финиш близко»
- Связь с дашбордом: утро — выбери 1 веху в топ-3, вечер — отметь done → прогресс роадмапа растёт, динамика коррелирует

## Дополнительная логика production
- **Привычки**: создание, удаление, тоггл на сегодня, прогресс-бар, шаблоны (Фокус/Тело/Разум/База), ежедневный выбор
- **Bio-чекин**: энергия/сон/фокус/настроение/заметка — 30 сек, сохраняет `daily_metrics`, влияет на Peak
- **Supabase + RLS**: `profiles`, `habits`, `habit_logs`, `daily_metrics`, `daily_rituals`, `roadmaps`, `milestones` — каждый видит только своё, realtime подписки, fallback в localStorage если таблицы ещё не созданы
- **Auth**: email/pass, без подтверждения (instant session), `middleware` защищает `/dashboard`, `/settings`, `/roadmap`, `next` param, `router.refresh`
- **Анимации**: Framer Motion на кнопках (spring 400), карточках, списках (AnimatePresence), header, hero; Three.js в hero — torus + icosahedron + particles
- **Настройки**: профиль, экспорт JSON/CSV, удаление данных, logout

## Флоу дня production
1. Утро 07:30 — открыл, прошёл утренний ритуал (намерение + топ-3) + отметил bio + выбрал привычки
2. День — делаешь дела
3. Вечер 21:00 — отметил привычки done, прошёл вечерний ритуал, оценил день → `daily_rituals` закрыт, `daily_metrics` обновлён, streak +1, график обновился, роадмап продвинулся
4. Неделя — смотришь динамику 7/30, heatmap, инсайты, корректируешь роадмап

Всё просто, но покрывает полный цикл: **утро → действие → вечер → динамика → роадмап**.
